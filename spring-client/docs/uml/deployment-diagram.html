Spring Client Deployment Diagram

This deployment view uses the runtime endpoints and ports configured by the codebase and repository instructions: the Spring Boot service on port 8080, MySQL on port 3306, the MetaTrader 5 REST gateway on port 5000, and CoinDCX external REST and WebSocket endpoints. The React frontend is shown as the primary client tier because the repository is structured as a three-tier system even though this page lives under the Spring module.

1. Runtime Deployment Topology

Main deployment view for local development and runtime operation. It shows the browser/frontend tier, the Spring Boot JVM, local persistence and logs, and external exchange and MT5 integrations.
