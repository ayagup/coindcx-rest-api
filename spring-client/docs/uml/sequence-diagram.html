Spring Client Sequence Diagrams

These diagrams capture the main runtime interactions visible in the current Spring Boot codebase: Socket.IO market-data ingestion, REST retrieval of persisted futures data, and futures order routing between CoinDCX and the local MetaTrader 5 gateway.

Based on CoinDCXWebSocketService, WebSocketDataPersistenceService, and FuturesInstrumentPriceParsingService. It shows startup connection, channel subscription, event routing, and the two most important persistence branches.

2. REST Query Of Persisted Futures Data

Based on WebSocketDataController. The controller serves candlesticks when a timeframe is supplied, otherwise it falls back from generic futures rows to parsed instrument-price snapshots.

100%
sequenceDiagram autonumber actor Client as React Frontend / API Consumer participant Controller as WebSocketDataController participant CandleRepo as WebSocketFuturesCandlestickDataRepository participant FuturesRepo as WebSocketFuturesDataRepository participant PriceService as FuturesInstrumentPriceParsingService participant PriceRepo as WebSocketFuturesInstrumentPriceRepository Client->>Controller: GET /api/websocket/data/futures/{contractSymbol}?timeframe=1h&limit=100 alt timeframe query parameter is present Controller->>Controller: TIMEFRAME_TO_DURATION.get("1h") -> "60" Controller->>CandleRepo: findByPairAndDurationWithLimit(pair, "60", limit) CandleRepo-->>Controller: candlestick rows ordered by open_time DESC Controller-->>Client: 200 OK with OHLCV candlesticks else timeframe absent Controller->>FuturesRepo: findByContractSymbolOrderByTimestampDesc(pair) alt generic futures rows are found FuturesRepo-->>Controller: WebSocketFuturesData list Controller-->>Client: 200 OK with limited futures events else fallback to parsed instrument prices FuturesRepo-->>Controller: empty result Controller->>PriceService: getRecentPrices(pair, limit) PriceService->>PriceRepo: findRecentByInstrument(pair, limit) PriceRepo-->>PriceService: parsed instrument prices PriceService-->>Controller: fallback price list Controller-->>Client: 200 OK with price fallback end end
