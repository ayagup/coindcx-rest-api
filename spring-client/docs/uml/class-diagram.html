Spring Client Class Diagrams

These class-diagram views focus on the core runtime types in the Spring Boot backend: REST controllers, application services, generated and Feign clients, repositories, and the entities/models that back market-data, MT5 registry, and logging workflows. Repeated generated request models and the long tail of near-identical repository types are intentionally omitted to keep the diagrams readable.

High-level class relationships across controllers, services, config, and external client abstractions. This view centers on the classes that orchestrate order routing and WebSocket ingestion.
