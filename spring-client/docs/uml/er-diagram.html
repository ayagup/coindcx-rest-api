CoinDCX MySQL ER Diagram

This ER diagram was generated from the live MySQL schema behind the `coindcx` database configured in Spring Boot. The database currently contains 23 tables, centered on WebSocket persistence for spot and futures market data, plus API logging, futures trade logs, and MetaTrader symbol metadata.

Database: coindcx
Engine: MySQL 8.4
Schema source: live database
The live schema currently has no declared foreign key constraints in `information_schema.KEY_COLUMN_USAGE`. Relationship lines in these diagrams are therefore logical links inferred from repeated business keys such as `order_id`, `position_id`, `pair`, `symbol`, `market`, and `currency_short_name`.
