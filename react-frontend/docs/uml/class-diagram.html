React Frontend Class Diagram

This class-diagram view models the frontend using the TypeScript interfaces, provider contracts, service objects, and React components that exist in the current codebase. Because the app is function-component driven rather than class-based, the diagrams focus on interface structure and dependency relationships rather than inheritance-heavy OO design.

App.tsx composes the provider tree, router shell, route guard, shared header, and page components. Auth and trade configuration are exposed through context contracts rather than class instances.
