React Frontend Deployment Diagram

These deployment views show how the React/Vite frontend is hosted in development and how the running browser application depends on environment configuration, local browser storage, and the Spring Boot backend. The diagrams are based on the current Vite server settings, `.env` values, and Axios service configuration in this codebase.

Vite dev server on 3000,
Spring API on 8080

1. Development Deployment Topology

Local development layout from the developer workstation to the browser, Vite dev server, React source modules, and the backend API target configured through both Vite proxying and `VITE_API_BASE_URL`.

2. Browser Runtime And Service Connectivity

The deployed client is a browser-hosted single-page app. It restores credentials and trade configuration from localStorage, routes between pages, and uses two Axios clients to call backend endpoints.

3. Build And Delivery View

Build-time packaging is simple: TypeScript compilation and Vite bundling produce static frontend assets that can be served by a static host or preview server, while runtime API calls still target the configured backend origin.
